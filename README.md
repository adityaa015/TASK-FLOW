# 📝 TaskFlow – Task Manager Web App

TaskFlow is a simple and clean Task Manager web application where users can add and remove tasks.  
It helps users organize daily work and stay productive.

---

## 🚀 Features
✔ Add new tasks  
✔ Delete tasks  
✔ Clean UI  
✔ Responsive layout  
✔ Runs directly in browser (no backend required)

---

## 🛠 Technologies Used
- HTML
- CSS
- JavaScript
